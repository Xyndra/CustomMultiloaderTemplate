# Custom Multiloader Template

This is my own custom multi-loader template, and it is not open-source, it is
source-available. I don't really mind if you use it, but I do not take responsibility
and I will get very angry if you try to impersonate me due to default settings.

Run this to install the template:

```bash
npx github:Xyndra/CustomMultiloaderTemplate#template-helper
```

Note that this requires Node.js and Git to be installed on your system.
